## 丽萨主机的VDS和VPS是什么关系？

在丽萨主机的产品体系里，VDS这个标签基本只挂在住宅IP产品线上。日本IIJ、台湾Hinet、德国、美国西雅图家宽这些带住宅属性IP的机器以VDS形式出售，而CN2 GIA、美国9929、新加坡BGP这类普通机房IP产品归在VPS名下。所以搜“丽萨主机VDS”，实际对应的就是它家的住宅IP VDS线。

## 固定流量还是不限流量？算一笔账

对绝大多数人来说，固定流量版更划算。以日本IIJ线为例：不限流量Lite月付1099元，比固定流量进阶版（399元/月、200Mbps、8000GB）贵出700元，带宽反而从200M降到100M。8000GB月流量折算下来每天260GB出头，运营几个社媒账号、日常挂流媒体基本用不完。不限流量版真正适合的是长期跑下载、做代理出口、多设备分摊这类流量确实压不住的场景。
